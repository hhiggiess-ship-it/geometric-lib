# Description
This library is designed to calculate the perimeter and area of geometric sha
# Math formulas
## Area
- Circle: S = πR²
- Rectangle: S = ab
- Square: S = a²
- Triangle: S = ah / 2


## Perimeter
- Circle: P = 2πR
- Rectangle: P = 2a + 2b
- Square: P = 4a
- Triangle: P = a + b + c

## Примеры вызова
circle.area(10)
circle.perimeter(5)

rectangle.area(4, 8)
rectangle.perimeter(3, 9)

square.area(5)
square.perimeter(12)

triangle.area(8, 5)
triangle.perimeter(5, 5, 6)
